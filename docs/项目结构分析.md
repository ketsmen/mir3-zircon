## 1. 项目概述

- **项目名称**：Legend of Mir 3 Zircon
- **仓库路径**：`D:\GitHub\mir3-zircon`
- **解决方案文件**：`Zircon Server.sln`
- **项目类型**：传奇3游戏私服客户端/服务端一体化项目
- **目标框架**：.NET 10（net10.0-windows8.0 / net10.0）
- **编程语言**：C#
- **UI框架**：Windows Forms + 自研 DirectX UI 控件
- **渲染引擎**：SharpDX (Direct3D 9/11) + Silk.NET (Vulkan)
- **音频引擎**：NAudio + DirectSound
- **数据库**：自研 MirDB ORM + Dapper + SQL Server
- **服务端UI**：DevExpress WinForms
- **插件系统**：反射加载 DLL
- **本地化**：StringMessages 抽象类 + INI 文件覆盖

## 2. 解决方案结构

解决方案 `Zircon Server.sln` 包含以下 12 个项目：

| 项目名称 | 类型 | 目标框架 | 主要职责 |
|---------|------|---------|---------|
| Client | WinExe | net10.0-windows8.0 | 游戏客户端主程序，输出 Zircon.exe |
| Server | WinExe | net10.0-windows8.0 | 服务端管理界面（DevExpress） |
| ServerCore | Exe | net10.0 | 服务端控制台入口（无UI） |
| ServerLibrary | Library | net10.0 | 服务端领域逻辑与数据模型库 |
| LibraryCore | Library | net10.0 | 共享基础库（枚举、配置、网络、模型） |
| Launcher | WinExe | net10.0-windows8.0 | 游戏启动器/补丁下载器 |
| Patcher | WinExe | net10.0-windows8.0 | 启动器自更新辅助程序 |
| PatchManager | WinExe | net10.0-windows8.0 | 补丁创建和上传工具 |
| ImageManager | WinExe | net10.0-windows8.0 | 图片格式转换工具 |
| LibraryEditor | WinExe | net10.0-windows8.0 | 图库编辑器 |

解决方案内还有两个虚拟文件夹：

- **Plugin**：包含 PluginCore、PluginStandalone

## 3. 项目依赖关系

```
LibraryCore (共享底座)
├── Client
├── Server ← PluginCore ← PluginStandalone
├── ServerCore ← ServerLibrary
├── ServerLibrary
├── PluginCore
└── PatchManager

Launcher (独立)
Patcher (独立)
ImageManager (独立)
LibraryEditor (独立)
```

**依赖说明**：
- `LibraryCore` 是横向共享底座，所有核心项目都依赖它
- `Client` 直接依赖 `LibraryCore`
- `Server` 同时依赖 `LibraryCore`、`PluginCore`、`ServerLibrary`
- `ServerCore` 依赖 `LibraryCore` 和 `ServerLibrary`
- `ServerLibrary` 依赖 `LibraryCore`
- `PluginCore` 依赖 `LibraryCore`
- `PluginStandalone` 依赖 `PluginCore`
- `PatchManager` 依赖 `LibraryCore`
- `Launcher`、`Patcher`、`ImageManager`、`LibraryEditor` 独立运行，不依赖项目内其他库

## 5. 关键技术组件

### 5.1 渲染系统

项目实现了三套渲染管线，通过 `RenderingPipelineManager` 统一管理：

- **SharpDX Direct3D 9**：旧版渲染后端，兼容性好但性能较低
- **SharpDX Direct3D 11**：默认渲染后端，性能和兼容性平衡
- **Silk.NET Vulkan**：新版渲染后端，性能最佳但仍在开发中

所有后端都实现了 `IRenderingPipeline` 接口，支持运行时切换。

### 5.2 音频系统

- 使用 **NAudio** 库加载 WAV、MP3 和 OGG 格式
- 使用 **DirectSound** 进行音频播放
- 通过 `DXSoundManager` 管理所有游戏声音
- 支持音量控制、循环播放和缓存过期

### 5.3 网络系统

- 基于 TCP 的自定义协议
- 使用反射进行数据包序列化/反序列化
- 支持异步发送/接收和数据包排队
- 包含诊断监控和超时管理

### 5.4 数据库系统

- **MirDB**：自研 ORM，使用二进制格式序列化
- 支持加密（AES-256）
- 支持 GZip 压缩备份
- 支持父子关系和级联删除
- 服务端还使用 **Dapper** + **SQL Server** 进行数据访问

### 5.5 插件系统

- 通过反射加载 `Plugin.*.dll` 文件
- 支持独立运行和集成到主应用程序
- 提供 DevExpress Ribbon UI 辅助工具
- 支持插件间消息通信

### 5.6 本地化系统

- 使用 `StringMessages` 抽象类定义翻译键
- 通过 `EnglishMessages` 和 `ChineseMessages` 提供默认值
- 运行时从 `Translations/*.ini` 文件加载覆盖值
- 客户端和服务端分离的翻译系统
- 支持按连接语言返回不同语言的消息
